# chumby-toolchain

A mirror of the CodeSourcery ARM GNU/Linux toolchain (2008q3-72) that Chumby
Industries published for the Chumby Classic, as it was at
http://files.chumby.com/toolchain/arm-2008q3-72-arm-none-linux-gnueabi-i686-pc-linux-gnu.tar.bz2.
That server refuses GitHub's runners (403), so
[neochumby](https://github.com/johnmerchant/neochumby)'s `classic/build`
fetches it from here.
